I am a Computer Science student at IBA Karachi, graduating in May 2027. I like working close to the hardware, where systems programming and machine learning meet the real constraints of the machine running them. My work so far runs from RISC-V assembly and an LLM runtime inside a teaching kernel to inference on a Raspberry Pi cluster.

Alongside my degree I am a teaching assistant at IBA, where I have worked on Programming, Computer Architecture and Operating Systems, and a founding member of **[Systems Research @ IBA](https://site-zeta-rust-98.vercel.app/)**, a student research group. My final year project, **[Project GLIDE](https://github.com/Project-GLIDE)**, is ongoing research on navigating a drone without GPS, using only the Earth's magnetic field. This year I also worked as a data science intern at Foretheta, evaluating and debugging a search ranking system.

A few things I have worked on:
- [xv6 LLM runtime](https://github.com/syedtaha22/xv6-llm-runtime-arch): LLaMA-2 inference running inside the xv6 teaching operating system
- [PiSSM](https://github.com/syedtaha22/PiSSM): distributed inference for state space models across a cluster of Raspberry Pi 5 boards
- [Othello engine](https://github.com/syedtaha22/othello-engine): Monte Carlo Tree Search guided by a distilled CNN
- [OctaC](https://github.com/Octa-C/compiler): a compiler for a statically typed language for numerical and matrix computation
